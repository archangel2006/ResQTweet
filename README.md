# ResQTweet
ResQTweet is an AI-powered disaster detection and summarization tool that analyzes tweets in real time. 
- By detecting crisis-related posts through natural language processing (NLP) and machine learning,
- ResQTweet provides timely alerts and concise summaries.

  ---
  
- This project contributes to UN Sustainable Development Goals
- SDG 11: Sustainable Cities & Communities, and
- SDG 13: Climate Action
  
  ...... by enabling faster disaster awareness, preparedness, and response.
